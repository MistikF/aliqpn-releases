<p align="center"><b>Один клиент для всех ваших VPN</b></p>

aliqpn подключается к чему угодно: VLESS с Reality и XHTTP, VMess, Trojan, Shadowsocks, Hysteria 2, WireGuard — и OpenVPN рядом с основным туннелем.

- **Маршруты под себя.** Российские сайты напрямую, заблокированные — через VPN, а для каждого сайта, адреса и приложения можно задать своё правило.
- **Не падает вместе с сервером.** Сервер перестал отвечать — aliqpn сам переключится на рабочий и вернётся, когда тот оживёт.
- **Ничего не утекает.** DNS, IPv6 и WebRTC идут по правилам, а встроенная проверка покажет, как вас видят сайты.
- **Всё под рукой.** Избранные серверы, статистика трафика, автозапуск, горячая клавиша, тонкие настройки подключения.

Для macOS 26 с интерфейсом на Liquid Glass и для Windows 10/11 x64.

## Установка

Установщики лежат в [Releases](../../releases).

### macOS

1. Скачайте `aliqpn-<версия>.dmg` и откройте его.
2. Перетащите aliqpn в «Программы».
3. Первый запуск (и сам DMG, если не открывается): macOS скажет, что не может проверить разработчика. Откройте «Системные настройки → Конфиденциальность и безопасность», внизу нажмите «Всё равно открыть» и подтвердите паролем. Это нужно один раз.
4. Вставьте ссылку на подписку и нажмите кнопку подключения. При первом подключении macOS один раз спросит пароль администратора — так ставится служба VPN.

Нужна macOS 26 или новее.

### Windows

1. Скачайте `aliqpn-setup-<версия>.exe` и запустите.
2. Windows может показать «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае». Это нужно один раз.
3. «Далее» → «Установить». Windows спросит разрешение на изменения — так ставится служба VPN.
4. Вставьте ссылку на подписку и нажмите кнопку подключения. aliqpn живёт в области уведомлений у часов.

Нужна Windows 10 22H2 или Windows 11, x64.

## О приложении

aliqpn не даёт серверов и подписок — это только клиент, свои серверы вы подключаете сами. Исходный код закрыт, здесь публикуются только готовые сборки.
